# 미션 - 다리 건너기

# 기능 목록
**1. [출력] 게임 시작 문구를 출력한다.**

**2. [입력] 다리 길이를 입력받는다.**
   - [예외 처리] 정수 타입이 아닐 경우 예외를 발생시킨다.
   - [예외 처리] 3 ~ 20 사이의 숫자가 아닐 경우 예외를 발생시킨다.

**3. [중간 과정] 다리를 생성한다.**
   - 무작위 값이 0이면 아래칸, 1이면 위칸을 건널 수 있다.

**4. [입력] 플레이어가 이동할 칸을 입력받는다.**
   - [예외 처리] U 또는 D가 아닐 경우 예외를 발생시킨다.

**5. [출력] 다리 건너기 결과를 출력한다.**
   - 건널 수 있으면 O로, 건널 수 없다면 X로 표시
   - 끝까지 건너면 게임 종료

**6. [입력] 다리 건너기를 실패한 경우 게임 재시작/종료 여부를 입력받는다.**
   - [예외 처리] R 또는 Q가 아닐 경우 예외를 발생시킨다.
   - 재시도 시 처음 만든 다리 재사용

**7. [출력] 게임 종류 문구를 출력한다.**
   - 다리 건넌 경로, 성공 여부, 시도 횟수
